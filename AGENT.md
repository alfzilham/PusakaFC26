# Agent Instructions

## GitHub Issue dan Pull Request

- Selalu tulis body Issue dan Pull Request sebagai Markdown multiline yang valid.
- Gunakan `--body-file` atau mekanisme yang mempertahankan newline sebenarnya.
- Jangan mengirim `\n` sebagai teks literal di dalam body GitHub.
- Gunakan heading, bullet list, dan checklist Markdown secara konsisten.
- Setelah membuat atau mengubah Issue/PR, buka kembali hasilnya untuk memastikan rendering Markdown sudah rapi.
